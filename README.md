# فيديو ٢ — Video2

تطبيق iOS شخصي (iPhone 11، iOS 16.4، TrollStore) لمتصفح مدمج، استخراج روابط الفيديو، التحميل، والمكتبة الأوفلاين.

لا يكسر DRM. إذا اكتُشف FairPlay / Widevine / PlayReady أو بث مشفّر بنظام ترخيص، يظهر تحذير داخل التطبيق ولا يُحمَّل المحتوى المحمي.

## المتطلبات

- macOS + Xcode 14 أو أحدث (SDK iOS 16)
- جهاز iPhone 11 بـ iOS 16.4 و TrollStore
- Bundle ID: `com.ahcrazy.video2`

## البناء بدون ماك (GitHub Actions)

1. ادفع الكود إلى GitHub (أو شغّل workflow يدوياً).
2. افتح المستودع → **Actions** → **Build IPA**.
3. بعد نجاح المهمة نزّل الأداة `Video2-TrollStore` وفيها `Video2.ipa`.
4. انقل الملف إلى الآيفون وثبّته من TrollStore.

الملف: `.github/workflows/build.yml` يعمل على `macos-13` بدون شهادة تطوير.

أوامر تقريبية بعد `xcodebuild`:

```bash
xcodebuild -project Video2.xcodeproj -scheme Video2 \
  -configuration Release -sdk iphoneos \
  CODE_SIGNING_ALLOWED=NO -derivedDataPath build
```

## المسارات المدعومة للاستخراج

- عنصر `<video>` / `<source>` و`currentSrc`
- اعتراض `fetch` و`XMLHttpRequest` و`Performance` للموارد
- ملفات `.mp4` `.m4v` `.webm` `.mov` `.m3u8` `.mpd`
- تحميل HLS (قوائم وتشغيلات محلية)
- لصق رابط يدوي
- تحذير DRM دون تجاوز الحماية

## ترجمة الفيديوهات (حتى 5 ساعات وأكثر)

نظام تفريغ ومراجعة وترجمة كامل داخل التطبيق لأي فيديو في المكتبة:

1. **استخراج الصوت** — من الفيديو المحمّل (HLS يُحوَّل مؤقتاً إلى MP4 أولاً) ويُعاد ترميزه AAC أحادي 16kHz ويُقطّع لأجزاء 15 دقيقة (~3.6MB للجزء).
2. **التفريغ الصوتي (STT)** — مزودات متعددة:
   - **Groq Whisper Turbo**: أجزاء متوازية (تُضبط من الإعدادات) — أسرع وأرخص، مناسب للفيديوهات الطويلة جداً.
   - **AssemblyAI Universal**: ملف واحد حتى 10 ساعات بلا تقطيع — أعلى دقة للطويل.
   - **STT.ai**: 600 دقيقة شهرية مجانية.
   - **Speechmatics**: 480 دقيقة مجانية شهرياً لدقة عالية مع اللهجات.
   - **SiliconFlow SenseVoice**: متعدد اللغات ويدعم العربية والهندية والصينية.
3. **مراجعة وتدقيق النصوص بالذكاء الاصطناعي (Free API)** — مراجعة دفعات نصوص التفريغ قبل الترجمة لضمان اكتمال السياق وتصحيح الأخطاء الصوتية (homophones)، إكمال الكلمات الناقصة، وإزالة هلاوس وتكرارات التعرف الصوتي عبر أي Free API بدون فيزا (**Gemini**, **Groq**, **Cerebras**, **SambaNova**, **OpenRouter**) مع تبديل تلقائي عند نفاد الحصة.
4. **الترجمة النصية السياقية** — ترجمة سياقية بالدفعات مع سياق الجُمل السابقة، عبر أي مزود بدون فيزا: **Gemini**، **Groq** (GPT-OSS 120B)، **OpenRouter** (قائمة حيّة من الموديلات المجانية :free — التطبيق يقرأ من الـ API العام ما هو مجاني فعلاً الآن، ولو توقف موديل مختار يُبدَّل تلقائياً بآخر حي)، **Cerebras** (مليون token/يوم)، **SambaNova** (DeepSeek/Llama)، أو **DeepL**.
5. **المخرجات وشاشة المراجعة والتعديل** — ثلاثة ملفات SRT: النص الأصلي المراجع، الترجمة، وثنائي اللغة — تظهر فوق المشغّل (زر CC: أصلي/مترجم/ثنائي + حجم خط) وقابلة للتصدير والمشاركة، مع شاشة متكاملة لمراجعة وتعديل أسطر الترجمة يدوياً أو إعادة تدقيقها وترجمتها بضغطة زر.

**الاستئناف**: كل جزء مفرَّغ وكل دفعة مراجعة وترجمة تُحفَظ لحظياً؛ لو انقطع الإنترنت أو أُغلق التطبيق تُكمل المهمة من نفس النقطة. ملفات الصوت المؤقتة تُحذف تلقائياً بعد الاكتمال، وإعادة الترجمة إلى لغة أخرى لا تعيد التفريغ.

**المفاتيح**: تُدخل من الإعدادات وتُخزَّن في Keychain. كل مزودات المراجعة والترجمة بدون فيزا ولها شريحة مجانية: Groq، Gemini، OpenRouter، Cerebras، SambaNova، DeepL — اختر منها من شاشة الإعدادات. فيديو 5 ساعات ≈ 20 جزءاً يكتمل عادة في دقائق معدودة مع Groq.

## التحميل والمكتبة

- تحميل HLS متوازٍ (عدة أجزاء معاً) مع اختيار الجودة (تلقائي / 360–1080p).
- استئناف التحميل من نقطة القطع، وحفظ الطابور بعد إغلاق التطبيق.
- تمرير كوكيز وترويسات الصفحة حتى تنجح روابط المواقع المحمية بتسجيل الدخول.
- استيراد من الملفات، ومجلدات داخل المكتبة، وتنظيف المساحة من الإعدادات.
- حذف مجلد HLS بالكامل مع القطع عند إزالة فيديو.
- **تحويل HLS بدون سحابة أولاً**: استخراج AAC مباشرة من أجزاء MPEG-TS (مع فك AES-128 إن وُجد المفتاح)، ثم AVFoundation عبر خادم محلي، ثم احتياطي سحابي متعدد: CloudConvert (نطاقات بديلة + تشخيص 403) → ffmpeg-api.com → ConvertAPI.

## المشغّل

- عناصر Now Playing على شاشة القفل والسماعات.
- **الدبلجة**: الفيديو اللي فيه دبلجة محفوظة بيشتغلها تلقائياً بدل الصوت الأصلي (مزامنة مستمرة وكتم الصوت الأصلي)، وزر الموجة للتفعيل/الإيقاف.
- **لقطة (Snapshot)**: التقاط أي مشهد وحفظه في ألبوم الصور.
- **AirPlay + مشاركة الفيديو + كتم الصوت + وضع أفقي/رأسي** من قائمة «المزيد».
- حفظ آخر سرعة تشغيل بين الجلسات.
- بحث داخل الترجمة والقفز للجملة.
- قراءة الترجمة بصوت Edge TTS (بدون مفتاح) مع احتياطي صوت الجهاز.
