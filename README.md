# فيديو ٢ — Video2

تطبيق iOS شخصي (iPhone 11، iOS 16.4، TrollStore) لمتصفح مدمج، استخراج روابط الفيديو، التحميل، والمكتبة الأوفلاين.

لا يكسر DRM. إذا اكتُشف FairPlay / Widevine / PlayReady أو بث مشفّر بنظام ترخيص، يظهر تحذير داخل التطبيق ولا يُحمَّل المحتوى المحمي.

## البحث السحري (Magic Search)

تبويب سادس (شريط تبويبات مخصص آمن بلا "More" النظامي) يبحث بالاسم في عدة مصادر **في وقت واحد**، ويشغّل ويحمّل النتيجة **من داخل التبويب نفسه** بلا رجوع للمتصفح:

- **أرشيف الإنترنت** — بدون مفتاح: أفلام الملكية العامة بملفات مباشرة وعدة جودات.
- **داليموشن** — بحث رسمي + `player/metadata` لاستخراج قوائم HLS بكل الجودات.
- **PeerTube** — عبر `sepiasearch.org` للبحث، ثم API المضيف نفسه (`/api/v1/videos/{uuid}`) لملفات MP4/HLS حقيقية.
- **فيميو** — `player.vimeo.com/video/{id}/config` (progressive + HLS) بدون مفاتيح.
- **يوتيوب** — طبقتان: بحث Piped + بحث Invidious للتسمية والمدة، وروابط التشغيل تُصطاد من الصفحة في المتصفح الخفي؛ إن لم تُوجد يُفتح المتصفح (النسخ العامة لـ Piped/Invidious محظورة من يوتيوب).
- **كل المواقع على الويب** — بحث ميتا بعدة محركات معاً (DuckDuckGo، SearXNG، Qwant، Brave، Mojeek، Bing Videos، Wikimedia Commons) مع فلترة مدة/جودة/حداثة من روابط المحركات نفسها.

### صيغة البحث (أوامر داخل نفس الحقل)
`اسم الفيلم مدة:1:36:00 جودة:1080 موقع:site.com استبعد:trailer سنة:1995 مصدر:archive ترتيب:views min:20 max:90`
— الأوامر تعمل بالعربي والإنجليزي (مدة/min، جود/hd، مصدر/source…)، ويمكن لصق **رابط** مباشر في الحقل ليُصيد منه فوراً. فلتر المدة يعطي كل نتيجة شارة (مطابق / قريب / مبتور) ويرتب الأقرب أولاً؛ الأزرار السريعة (+5د، +20د…) تضبط الحد الأدنى.

### التشغيل داخل التبويب
- `MagicResolver` يحوّل النتيجة إلى **مصادر تشغيل** (ملف مباشر أو قائمة HLS + جودات مفردة).
- `MagicStreamProxy` وسيط محلي (127.0.0.1) يمرر ترويسات الموقع (Referer/UA/Cookie) ويعيد كتابة قوائم HLS — لأن `AVPlayer` لا يرسل ترويسات؛ إن فشل المسار المباشر يجرّب الوسيط ثم الجودة التالية ثم يعرض بدائل.
- تبديل الجودة أثناء التشغيل مع حفظ الموضع، صورة مصغّرة قبل أول لقطة، شريط «يُشغَّل الآن» أسفل التبويب يُبقي الصوت شغّالاً بعد إغلاق نافذة المشغّل، وأزرار Now Playing في شاشة القفل.

### الصيد العميق (Hunter)
`MagicPageHunter` يفتح صفحة النتيجة في **WKWebView خفي** بنفس إعدادات المتصفح الظاهر (نفس UA ونفس مخزن الكوكيز) خارج الشاشة لكن **داخل نافذة حقيقية وغير مخفي** — حتى تعدّه WebKit صفحة «مرئية» فتعمل مؤقتاته ومشغّلاته الكسولة طبيعياً. يُحقن بنفس `ExtractorScript` المستخدم في المتصفح + خطّاف على `fetch/XHR` لردّ `youtubei/player` الداخلي، ثم يلتقط ما تولّده السكربتات من روابط. إضافة إلى ذلك:

- **محرك نقر** يعمل في كل الإطارات (الصفحة الأم + مشغّلات iframe): يحاكي لمسة مستخدم حقيقية (touch/pointer/mouse + click بإحداثيات العنصر) على أزرار التشغيل المعروفة (video.js / jwplayer / plyr / shaka…) وعلى ما يغطي الفيديو نفسه (بوستر/أوفرلاي) — للمواقع التي لا تطلب ملف الفيديو إلا بعد نقرة، ويكرر المحاولة على جدول زمني دون انتظار اكتمال تحميل الصفحة (صفحات SPA).
- **تحضير مبكر للصفحة**: `visibilityState = visible`، وتحميل العناصر الكسولة (`data-src`) فوراً، وعدم تعطيل أي شيء بسبب `IntersectionObserver`.
- **حاجز تنقّل**: تُمنع النوافذ المنبثقة وأي انتقال من الصفحة الأم بعد استقرارها حتى لا تؤدي نقرة المحاكاة إلى مغادرة الصفحة نحو إعلان.
- **كوكيز الجلسة** (نفس مخزن المتصفح) تُلحق بمصادر الصيد كما في مسار المتصفح (`BrowserAuth`).
- يعمل الصيد تلقائياً حتى مع إطفاء «الصيد العميق» إن رفض الموقع الطلب المباشر (خطأ resolve.fetchFailed)، وعند كل ضغطة «تشغيل»/«صيد أعمق»/لصق رابط، ولو فشلت محاولة سابقة.

قراءة فقط: لا يحمّل ولا يخزّن شيئاً، ولا يلمس تبويب المتصفح ولا `BrowserModel`.

### التحميل
كل أزرار التحميل (من شريط الجودة أو قائمة «تحميل بالجودة») تمر عبر **نفس** `DownloadManager.enqueueManual` الأصلي — أُضيف له وسيط اختياري `kindHint:` فقط لتسمية روابط CDN بلا امتداد، و`job(matchingURL:)` لعرض شريط التقدم داخل التبويب. شريط HLS لا يُستخدم في التحميل إطلاقاً. **لا يوجد أي تعديل على خط التحميل أو الاستخراج، ولا كسر لأي DRM**: إن ظهرت حماية (FairPlay/Widevine/`drm/`/`cbcs`) تُستبعد تلك المصادر ويُعرض المتصفح كبديل.

## المتطلبات

- macOS + Xcode 14 أو أحدث (SDK iOS 16)
- جهاز iPhone 11 بـ iOS 16.4 و TrollStore
- Bundle ID: `com.ahcrazy.video2`

## البناء بدون ماك (GitHub Actions)

1. ادفع الكود إلى GitHub (أو شغّل workflow يدوياً).
2. افتح المستودع → **Actions** → **Build IPA**.
3. بعد نجاح المهمة نزّل الأداة `Video2-TrollStore` وفيها `Video2.ipa`.
4. انقل الملف إلى الآيفون وثبّته من TrollStore.

الملف: `.github/workflows/build.yml` يعمل على `macos-13` بدون شهادة تطوير.

أوامر تقريبية بعد `xcodebuild`:

```bash
xcodebuild -project Video2.xcodeproj -scheme Video2 \
  -configuration Release -sdk iphoneos \
  CODE_SIGNING_ALLOWED=NO -derivedDataPath build
```

## المسارات المدعومة للاستخراج

## ترجمة الفيديوهات (حتى 5 ساعات وأكثر)

نظام تفريغ ومراجعة وترجمة كامل داخل التطبيق لأي فيديو في المكتبة:

1. **استخراج الصوت** — من الفيديو المحمّل (HLS يُحوَّل مؤقتاً إلى MP4 أولاً) ويُعاد ترميزه AAC أحادي 16kHz ويُقطّع لأجزاء 15 دقيقة (~3.6MB للجزء).
2. **التفريغ الصوتي (STT)** — مزودات متعددة:
   - **Groq Whisper Turbo**: أجزاء متوازية (تُضبط من الإعدادات) — سريع للفيديوهات الطويلة؛ راجع تسعير وحدود مشروع Groq قبل المهمة.
   - **AssemblyAI Universal**: ملف واحد حتى 10 ساعات بلا تقطيع؛ منحته التسجيلية المعلنة 50$ بلا بطاقة.
   - **Deepgram Nova-3**: رصيد تسجيل معلن 200$ بلا تاريخ انتهاء ولا بطاقة، مع تفاصيل الرصيد الفعلية في Console.
   - **Speechmatics**: خطة Free بمنحة 100$ وحد batch موثق 10 ساعات/شهر (600 دقيقة) بلا بطاقة.
   - **STT.ai**: يعلن 600 دقيقة ويب و100 دقيقة API شهرياً بلا بطاقة، لكن معلومات API متعارضة بين صفحاته؛ اختبره بمقطع قصير أولاً.
   - **SiliconFlow SenseVoice**: متعدد اللغات؛ تحتاج النماذج المجانية إلى تحقق هوية، ولم تُثبت سياسة بلا بطاقة عامة.
   - **Azure Speech**: حصة F0 مفيدة، لكن حساب Azure Free القياسي يحتاج وسيلة دفع (حساب Students استثناء بتحقق الطالب).
3. **مراجعة وتدقيق النصوص بالذكاء الاصطناعي** — مراجعة دفعات نصوص التفريغ قبل الترجمة لضمان اكتمال السياق وتصحيح الأخطاء الصوتية وإزالة الهلاوس والتكرار. الخيارات المؤكدة بلا وسيلة دفع ضمن شروطها هي **Gemini** (موديلات/بلدان مؤهلة)، **SambaNova Free**، و**OpenRouter Free**؛ يمكن للتطبيق أيضاً استعمال Groq أو Cerebras عندما يملك المستخدم مفتاحاً، لكن Groq لا تُدّعى له أهلية بلا بطاقة هنا، بينما تجربة Cerebras الحالية (5$ لـ30 يوماً) تتطلب وسيلة دفع موثقة.
4. **الترجمة النصية السياقية** — ترجمة بالدفعات مع سياق الجُمل السابقة عبر Gemini أو Groq (GPT-OSS 120B)، وOpenRouter (قائمة حية من موديلات `:free` و`openrouter/free`؛ 20 طلب/دقيقة و50/يوم بلا شحن)، وSambaNova (20 طلباً/يوم و200K token/يوم في Free Tier)، أو DeepL/Cerebras عند تفعيل حسابهما. لا يفترض التطبيق أن DeepL أو Groq أو SiliconFlow أو ElevenLabs أو Cloudflare متاحون بلا بطاقة عالمياً؛ راجع شروط الحساب والمنطقة.
5. **المخرجات وشاشة المراجعة والتعديل** — ثلاثة ملفات SRT: النص الأصلي المراجع، الترجمة، وثنائي اللغة — تظهر فوق المشغّل (زر CC: أصلي/مترجم/ثنائي + حجم خط) وقابلة للتصدير والمشاركة، مع شاشة متكاملة لمراجعة وتعديل أسطر الترجمة يدوياً أو إعادة تدقيقها وترجمتها بضغطة زر.

**الاستئناف**: كل جزء مفرَّغ وكل دفعة مراجعة وترجمة تُحفَظ لحظياً؛ لو انقطع الإنترنت أو أُغلق التطبيق تُكمل المهمة من نفس النقطة. ملفات الصوت المؤقتة تُحذف تلقائياً بعد الاكتمال، وإعادة الترجمة إلى لغة أخرى لا تعيد التفريغ.

**المفاتيح**: تُدخل من الإعدادات وتُخزَّن في Keychain. لا تعني شارة «مجاني» أن الحساب مؤهل دائماً أو أن الاستخدام غير محدود: يعرض التطبيق الحدود المتاحة ويبدّل المزود عند أخطاء الحصة، لكنه لا ينفذ التسجيل أو التحقق أو الفوترة نيابة عنك. نتائج التحقق وروابط المصادر الحالية موثقة في [`docs/api-availability-audit-2026-09-05.md`](docs/api-availability-audit-2026-09-05.md).

## التحميل والمكتبة

- تحميل HLS متوازٍ (عدة أجزاء معاً) مع اختيار الجودة (تلقائي / 360–1080p).
- استئناف التحميل من نقطة القطع، وحفظ الطابور بعد إغلاق التطبيق.
- تمرير كوكيز وترويسات الصفحة حتى تنجح روابط المواقع المحمية بتسجيل الدخول.
- استيراد من الملفات، ومجلدات داخل المكتبة، وتنظيف المساحة من الإعدادات.
- حذف مجلد HLS بالكامل مع القطع عند إزالة فيديو.
- **تحويل HLS بدون سحابة أولاً**: استخراج AAC مباشرة من أجزاء MPEG-TS (مع فك AES-128 إن وُجد المفتاح)، ثم AVFoundation عبر خادم محلي، ثم احتياطي سحابي متعدد: CloudConvert (نطاقات بديلة + تشخيص 403) → ffmpeg-api.com → ConvertAPI.

## المشغّل

- عناصر Now Playing على شاشة القفل والسماعات.
- **الدبلجة**: الفيديو اللي فيه دبلجة محفوظة بيشتغلها تلقائياً بدل الصوت الأصلي (مزامنة مستمرة وكتم الصوت الأصلي)، وزر الموجة للتفعيل/الإيقاف. يدعم Groq Orpheus (إنجليزي وعربي سعودي؛ WAV وحد 200 حرف لكل جملة) بدلاً من PlayAI المتوقف، إضافة إلى Edge والمزودات الأخرى.
- **لقطة (Snapshot)**: التقاط أي مشهد وحفظه في ألبوم الصور.
- **AirPlay + مشاركة الفيديو + كتم الصوت + وضع أفقي/رأسي** من قائمة «المزيد».
- حفظ آخر سرعة تشغيل بين الجلسات.
- بحث داخل الترجمة والقفز للجملة.
- قراءة الترجمة بصوت Edge TTS (بدون مفتاح) مع احتياطي صوت الجهاز.
