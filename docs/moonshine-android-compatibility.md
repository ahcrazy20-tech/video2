# Kadr 2.6.1 / 22 · English rapid-route crash protection

On an S26 Ultra, the user reported that Kadr closed as soon as **Rapid English → Arabic (Moonshine + Firefox)** started transcribing. This route does not use the new Silero detector. The handset's crash stack was not available.

[Moonshine #253](https://github.com/moonshine-ai/moonshine/issues/253) documents the matching failure at ONNX Runtime session creation on Snapdragon 8 Elite Gen 5: the bundled ORT 1.23.2 can dispatch an SME2 instruction on a CPU that advertises SME but not SME2, resulting in a process-ending `SIGILL`. Kadr uses `ai.moonshine:moonshine-voice:0.1.6`. The v0.1.5 and v0.1.6 upstream ARM64 Android vendor entries both point to the same 6,291,928-byte ORT binary (LFS SHA‑256 `86e85022fc539963177e478c8e9a8a8219bc3b0d7515bf5297a62986dbc45e7a`). The v0.1.6 build pins ORT 1.23.2 and leaves KleidiAI enabled for Android ARM64. [Upstream PR #254](https://github.com/moonshine-ai/moonshine/pull/254) proposes a new build with KleidiAI disabled; it is not an upgraded artifact in this release.

- Kadr reads `AT_HWCAP2` through its portable JNI library, using the [Linux AArch64 SME and SME2 bits](https://github.com/torvalds/linux/blob/v6.18/arch/arm64/include/uapi/asm/hwcap.h). On SME without SME2, or if the probe cannot run, it will not open the bundled Moonshine JNI or ORT. It does not blacklist a device name or disable compatible phones. Re-audit this guard when the AAR changes.
- The English shortcut on a blocked device selects compatible installed Whisper and the existing Firefox EN→AR pack, with CPU and silence skipping off initially. It prefers installed Small for clear speech, then another compatible installed Whisper, otherwise offers Small as an explicit download. No model is removed or downloaded automatically, and no audio is sent off the phone.
- An incomplete paused Moonshine job offers **New job with Whisper** for the same video. It does not continue the old speech checkpoints with a different engine. A job with a complete transcript can still finish translation or retranslate it with another model; it never opens Moonshine for that.

Regression checks cover SME-only, SME+SME2, no SME, and an unreadable probe. A host JNI run with injected `AT_HWCAP2` values verifies the actual bridge and that the guard runs before reading Moonshine weights. Pipeline tests verify both blocking new ASR and translating an existing English transcript with Firefox. These are not tests on an S26 Ultra.

**Build verification.** [Android CI run 44544896993](https://github.com/ahcrazy20-tech/video2/actions/runs/44544896993) passed `:app:testDebugUnitTest` and `:app:assembleDebug` for `f1495d5e0ff4aaf2d45c341446a4ad16a633415d`. The [Video2-Android artifact](https://github.com/ahcrazy20-tech/video2/actions/runs/44544896993/artifacts/14540793882) contains `app-debug.apk`; GitHub lists the ZIP as 50,380,831 bytes with SHA‑256 `cf3294b04ee21a8046a3afe2a444bfa335a1599fd5ff4e2ff9990b7a7fe5b10f`. The sandbox could not retrieve the redirected ZIP, so neither signer matching nor on-device inference was verified.

**Safe update and handset check.** The CI APK is a debug build, not a guarantee of a signature match. Compare the APKs with `apksigner verify --print-certs` if both are available, or use a build signed in the original signing environment. If Android refuses the update, do not uninstall or clear storage. On the existing version, start a new on-device job with explicit English → Arabic, an installed compatible Whisper model and Firefox EN→AR; use CPU with silence skipping off for this check.

After an in-place update on the affected phone, reopen the interrupted job or create a new English rapid job. Confirm the speech model shows Whisper, then try a short saved MP4. Verify the SRT completes without the app closing; keep the existing job and library. If the app still closes, record the speech model and stage. On a trusted ADB connection, `adb shell dumpsys activity exit-info com.ahcrazy.video2` can show the most recent exit reason; share only the relevant entry with any private paths redacted. No video or private transcript is needed. This is a compatibility fallback, not a repair of the vendor Moonshine binary, and Whisper performance can differ from Moonshine.
